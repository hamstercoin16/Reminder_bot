<h1 align="center">📌Project Idea</h1>

<p align="center">
    Simplifies candidate or another person's filtering directly in Telegram.<br>
    Bot for HR specialists, recruiters and small team leaders.
</p>

---

<h2>Main Target</h2>

<ul>
  <li>Organize candidate information</li>
  <li>Simplify filtering process</li>
  <li>Manage recruitment workflow inside Telegram</li>
</ul>

---

<h2>Installing & Running</h2>

<pre><code># 1. Clone repository
 git clone https://github.com/hamstercoin16/Kandidate-reminder-bot

# 2. Create virtual environment
python -m venv .venv

# 3. Activate environment
 Windows
 .venv\Scripts\activate
 Mac / Linux
 source .venv/bin/activate

# 4. Install dependencies
pip install -r requirements.txt

# 5. Crate file .env 
<p>In this file you must write
BOT_TOKEN="Add your bot token, its can be from BotFather"
</p>

# 6. Run the bot
 run file 'main.py'
</code></pre>
